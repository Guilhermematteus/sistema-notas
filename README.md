# 📚 Sistema de Gerenciamento Acadêmico (Java)

Projeto desenvolvido com o objetivo de praticar os fundamentos da **Programação Orientada a Objetos (POO)** e a manipulação de estruturas de dados em **Java**, simulando um sistema simples de controle de notas e status de alunos via terminal.

## 🚀 Tecnologias Utilizadas
* **Java** (Linguagem principal)
* **Programação Orientada a Objetos (POO)**
* **Git e GitHub** (Versionamento de código)

## ⚙️ Funcionalidades
1. **Cadastro de Alunos:** Permite registrar o nome do aluno e duas notas obtidas.
2. **Cálculo Automático de Média:** Aplica a regra de negócio para tirar a média aritmética das notas.
3. **Verificação de Situação:** Classifica automaticamente o aluno em *Aprovado*, *Recuperação* ou *Reprovado* com base na média.
4. **Listagem em Memória:** Armazena os registros em uma lista dinâmica (`ArrayList`) enquanto a aplicação está em execução.
